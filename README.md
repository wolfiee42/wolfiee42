## About Me

I'm a full-stack engineer with a backend-first mindset — I like systems that are reliable under load, easy to reason about, and built to survive contact with real users. My comfort zone is the space between a clean API and a clean UI: designing the data model and auth/billing logic on one end, then shipping a polished React/Next.js interface on the other.

I care about **production quality over tutorial quality** — proper error handling, sane deployment pipelines, and architecture decisions that hold up six months later, not just on day one.

- 🔭 Currently deep in backend architecture — auth systems, billing/subscription logic, and cloud-native deployments
- 🧩 Comfortable owning a feature end-to-end: schema → API → frontend → deployment
- 🤖 Increasingly exploring AI/LLM integrations (RAG, agentic workflows) in production apps
- 🌱 Long-term focus: writing systems that are boring in the best way — predictable, observable, maintainable
